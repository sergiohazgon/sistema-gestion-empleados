# Sistema de gestión de empleados

Aplicación de consola desarrollada en Java para gestionar usuarios y trabajadores mediante autenticación, roles y persistencia en ficheros.

El proyecto aplica conceptos de Programación Orientada a Objetos como herencia, encapsulación y separación de responsabilidades.

## Funcionalidades

- Inicio de sesión de usuarios.
- Gestión de distintos roles.
- Alta de trabajadores.
- Baja de trabajadores mediante DNI.
- Consulta de información de trabajadores.
- Gestión de fichajes.
- Registro de horas trabajadas.
- Persistencia de trabajadores mediante serialización.
- Lectura y escritura de ficheros.

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos
- Herencia
- Colecciones
- Serialización
- Ficheros
- IntelliJ IDEA

## Estructura del proyecto

El proyecto está organizado en diferentes paquetes para separar la lógica de la aplicación:

- `model`: clases que representan los usuarios y trabajadores.
- `controller`: clases encargadas de gestionar usuarios y fichajes.
- `Main`: punto de entrada de la aplicación.

## Persistencia

La aplicación utiliza ficheros para almacenar información de trabajadores y registrar los fichajes realizados.
